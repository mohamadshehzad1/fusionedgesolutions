Technical SEO & Next.js/Cloudflare Pages Notes
We will implement Next.js with the App Router for modern routing. Key points:

Rendering Strategy: Static export (SSG via `output: "export"`) for all pages so crawlers see full HTML. Forms are handled client-side and submitted via a Cloudflare Pages Function in `/functions`.
Routing: Use file-based routing; e.g. /housing-disrepair/[topic].tsx for each cluster topic. Implement 301 redirects via `public/_redirects` and security/cache headers via `public/_headers`.
Performance: Optimize images (unoptimized on export, modern WebP formats) and lazy-load offscreen content. Cloudflare Pages provides CDN and Brotli compression. Ensure Core Web Vitals targets (LCP <2.5s, FID <100ms).
Meta & Schema: Configure meta tags per page for titles/descriptions. Add JSON-LD schemas: WebPage, LegalService (with firm info), Organization/LocalBusiness (with address/phone) and FAQPage schema on FAQ sections.
Internationalization: Not needed beyond UK (no hreflang required).
Hosting: Deploy to Cloudflare Pages from an `out/` static export. Use `robots.txt` + `sitemap.xml` for discoverability, and `wrangler` for local preview of Functions.
